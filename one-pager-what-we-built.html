The Problem

A streaming platform must decide which ad each individual viewer sees — in under two seconds, across thousands of concurrent streams. The system handles three distinct ad formats: break ads (mid-content, non-skippable), pause ads (contextual Brand CTA or Sponsored Product Listing triggered on pause), and binge-aware frequency control (ad load tapers across consecutive episodes, resets on session break). Live TV runs on SCTE-35 broadcast cues; VOD on chapter-marker triggers. Both share the same AI decisioning pipeline — budget caps, compliance rules, frequency limits, and a Vickrey auction enforced per decision.

Key Design Decisions
⚡
Deterministic code over LLMs for rules
Inventory, compliance, and tracking are structured rule evaluation — fast, testable, no LLM cost. Claude only where judgment is needed.
⚖️
Second-price (Vickrey) auction
Dominant strategy: bid your true value. Eliminates bid-shading, produces efficient and stable prices. Industry standard for programmatic CTV.
🔄
8-state state machine
Agents propose, state machine validates. Concurrent events and partial failures can't corrupt system state.
📝
Full audit trail on every decision
Claude's complete chain-of-thought stored per break. Every ad decision queryable, explainable, and accountable.
🎬
One engine, two content modes
Same decisioning pipeline serves both live TV (SCTE-35) and VOD (chapter markers). VOD unlocks richer personalisation — the platform knows exactly what content the viewer chose.
⏸️
Pause ads in two formats
When a viewer pauses, a contextual ad appears after 1.5s. Brand CTA (app/web conversion) for service advertisers; Sponsored Product Listing (single product + Shop CTA) for product advertisers. Format is campaign-driven, not random.
📈
Binge frequency intelligence
Ad load tapers across consecutive episodes: 3 breaks → 2 → 2 → 1, then resets. Session break detection (30m idle or new login) restores full load. Suppressed breaks are marked in the timeline — viewers see fewer ads, not a broken experience.
⚙️
Zero hardcoded settings
Floor CPM, daypart multipliers, frequency caps all read from database at runtime. Operators tune without code deploys.

Session Intelligence
Binge tracking adapts ad load across episodes — detects continuous viewing vs session breaks without explicit user input
