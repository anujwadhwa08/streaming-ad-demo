Technical architecture — three-layer breakdown
01 — Protocol Layer
📡 SCTE-35
ANSI standard for digital program insertion. Binary splice insert commands embedded in MPEG-TS streams signal downstream systems 6 seconds before the ad slot.
MPEG-TS splice_insert() 6s lead time
📺 HLS Stitching
Content and ad segments have independent PTS bases. EXT-X-DISCONTINUITY at every content↔ad boundary signals HLS.js to flush its decoder and reinitialise timestamp state.
EXT-X-DISCONTINUITY PTS reset MSE
📊 VAST Beacons
IAB standard tracking. 7 events per impression: Impression, Start, 1st Quartile, Midpoint, 3rd Quartile, Complete, Skip. Logged to Supabase; fire real HTTP in production.
IAB VAST 3.0 7 events DEMO_MODE
02 — Decisioning Layer
🔍 Inventory + Compliance
Pure deterministic JavaScript. Inventory filters 8 campaigns by budget, audience segment, content category, and geography. Compliance evaluates frequency caps and competitive separation. Fast, testable, no LLM latency.
~5ms deterministic no LLM
⚖️ Vickrey Auction
Second-price auction: winner pays the second-highest bid. Floor CPM, daypart multipliers (primetime 1.2×), and max candidates are read from platform_settings at runtime. Zero hardcoded values.
2nd-price daypart multipliers runtime config
✦ Claude Sonnet Decision
Only LLM in the pipeline. Reviews auction winner against viewer segment, content context, and compliance result. Returns confirmation + full chain-of-thought reasoning stored in audit_log per break.
claude-sonnet-4-6 chain-of-thought auditable
03 — Data + Infrastructure
🗄️ Supabase (PostgreSQL)
Four core tables. All platform settings read at runtime. Audit log stores full agent reasoning JSON. Reset endpoint clears all state atomically between test runs.
campaigns ad_breaks audit_log platform_settings
🔄 State Machine
8-state machine wraps the entire pipeline. Agents propose, state machine validates. Invalid transitions are rejected cleanly — prevents state corruption from concurrent events or partial failures.
8 states state machine propose/validate
🚀 Runtime
Node.js + Express. Deployed on Railway. Dashboard polls /api/dashboard every 3s. SSAI manifest served per-viewer per-poll. No websockets — pure HTTP polling and REST.
Node.js Express Railway REST
